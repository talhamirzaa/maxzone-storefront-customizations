# Maxzone Clothing — Shopify Custom Sections & Fixes

**Live site:** [maxzoneclothing.com](https://maxzoneclothing.com/)
**Platform:** Shopify (Dawn-based theme)
**My role:** Ongoing development — built custom sections not available in
the base theme, and fixed existing issues (performance, responsiveness,
cross-browser bugs).

This repo is a collection of the custom Shopify Liquid sections and fixes
I built for this store, each documented as a mini case study with code and
screenshots.

> Note: this repo contains only the custom code I wrote (sections,
> snippets, scripts), not the full store theme, which is the client's
> property.
