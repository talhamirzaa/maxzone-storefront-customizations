# Maxzone Clothing — Storefront Customizations

**Live site:** [maxzoneclothing.com](https://maxzoneclothing.com/)

Custom sections and features built for this e-commerce storefront —
things not available out of the box in the base theme, plus targeted
fixes and enhancements. Each one is documented as a mini case study with
code and screenshots.
